# Provider Account Display Unification

## 目标

统一管理后台所有 provider 账号名称展示规则：优先展示邮箱和手机号，有哪个显示哪个，两个都有时同时显示；点击账号名称复制可识别的账号信息。

## 非目标

- 不改变账号调度、配额、健康状态和计费逻辑。
- 不改变账号名称、密钥名称、OAuth 配置的存储格式。
- 不新增复杂配置项。

## 行为变化

- 后端管理接口补充 `oauth_email`、`oauth_phone` 或账号标签字段，前端优先使用这些字段展示账号。
- 前端统一使用同一套显示规则：`oauth_email`、`oauth_phone`、手机号兼容字段优先；没有联系方式时回退原账号名。
- 点击账号显示文本时复制邮箱和手机号；两者都有时复制为多行文本。
- 号池管理桌面表格支持拖动调整列宽。
- 使用记录列表的转移标记必须展示真实服务路径，例如 `cc-max(link)1.0 → cc-max(zzshu)1.0`。账号名只作为账号信息展示，不能当成转移目标。

## 影响范围

- 供应商详情里的账号管理列表。
- 号池管理桌面表格和移动卡片。
- 提供商优先级管理弹窗里的账号列表。
- 模型路由预览里的账号列表。
- 使用记录、请求时间线、模型测试和性能分析里的 provider 账号展示。
- Gemini 文件管理里的可用账号和映射账号展示。
- 管理端 provider key、号池 key、路由预览和 key 分组接口返回字段。

## 验证方式

- 运行后端格式化和相关管理接口测试。
- 运行前端类型检查。
- 手动确认邮箱、手机号、无联系方式三种账号都能正确显示和复制。
- 手动确认发生服务切换的使用记录显示服务 A 到服务 B；未发生服务切换的记录不显示转移箭头。
