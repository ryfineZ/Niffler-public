# 邀请返利金额读取修复

## 目标

修复 PostgreSQL 线上库金额列为 `numeric` 时，邀请返利流程按 `f64` 直接读取导致返利处理提前失败的问题。

## 非目标

- 不改变邀请返利开关、比例、人头返利或触发时机。
- 不自动补发历史漏发返利。
- 不调整支付订单、钱包余额或返利表结构。

## 行为变化

- 邀请返利读取支付订单金额、返利金额和钱包余额时，PostgreSQL 查询显式转成 `DOUBLE PRECISION`。
- 支付成功后，返利流程可以继续写入首付订单、返利记录和赠款钱包流水。

## 影响范围

- 影响邀请返利的支付成功处理、返利列表、返利重试和退款冲回。
- 不影响支付主流程；支付主流程原本已经对金额列做了显式转换。

## 验证方式

- 运行邀请返利相关单元测试。
- 运行架构回归测试，确认 PostgreSQL 返利 SQL 对 `numeric` 金额列有显式转换。
