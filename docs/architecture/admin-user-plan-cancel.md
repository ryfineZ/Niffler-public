# 后台取消用户套餐

## 目标

后台用户套餐弹窗支持取消一份当前有效套餐。取消后，这份套餐立即不再提供周期额度和会员权益。

## 非目标

- 不删除历史订单。
- 不退款。
- 不改变用户自己购买套餐的流程。
- 不改变同套餐续费顺延规则。

## 行为变化

- 管理员可以在用户当前有效套餐列表中点击“取消套餐”。
- 系统把对应套餐权益标记为 `cancelled`，并把到期时间压到当前时间。
- 取消后的套餐不会再参与套餐额度判断，也不会再给用户带来会员分组权益。
- 取消动作只影响这份用户套餐权益，不影响套餐模板和历史支付订单。

## 影响范围

- 后台用户管理里的“用户套餐”弹窗。
- 后台用户套餐管理接口。
- `user_plan_entitlements` 中的单条权益状态。

## 验证方式

- 有效套餐取消后，用户套餐列表不再显示这份套餐。
- 再次取消同一份套餐会返回不存在或已失效。
- 取消接口不会删除订单和套餐模板。
