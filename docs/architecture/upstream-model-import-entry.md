# 上游模型批量导入入口

## 目标

在提供商详情的模型列表中增加直接入口，让管理员可以先读取上游 API 返回的模型列表，再批量导入到当前提供商，减少逐个手动添加模型的操作。

## 非目标

- 不改变上游模型获取协议。
- 不改变模型价格、倍率、套餐可用模型的计算规则。
- 不新增新的后端接口，优先复用已有上游模型查询和导入接口。

## 行为变化

- 提供商详情的“模型列表”区域新增“从上游获取”按钮。
- 点击后打开“获取上游模型”弹窗，系统读取当前提供商所有可用密钥能访问的上游模型。
- 管理员可以勾选多个上游模型并一次导入。
- 导入完成后刷新当前提供商的模型列表和模型映射。

## 影响范围

- 只影响管理后台的提供商模型管理界面。
- 上游必须支持模型列表接口；不支持模型列表的第三方 API 仍需要手动添加或使用已有全局模型关联。
- 读取上游模型时会调用上游接口，但前端会复用已有请求合并逻辑，后端也已有缓存能力，避免重复请求。

## 验证方式

- 打开提供商详情，确认模型列表出现“从上游获取”按钮。
- 点击按钮，确认能打开上游模型弹窗。
- 选择模型导入后，确认模型列表刷新并出现新模型。
- 运行前端类型检查或构建，确认没有类型错误。
