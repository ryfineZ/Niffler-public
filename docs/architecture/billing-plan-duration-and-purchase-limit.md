# 套餐有效期与购买限制拆分

## 目标

套餐编辑页把“套餐有效期”和“重复购买限制”作为两个独立设置展示，避免管理员选择“不限购”后看不到有效期，但系统仍按隐藏旧值计算到期时间。

## 非目标

- 不改变套餐数据表结构。
- 不改变用户购买、后台发放和支付成功后的开通规则。
- 不自动修正已经存在的历史套餐配置。

## 行为变化

- 套餐有效期始终显示，字段名改为“套餐有效期”。
- 套餐有效期始终必填，单位仍为日、月、年。
- 重复购买限制只控制同一用户能否重复购买，不再决定有效期字段是否显示。
- 套餐列表的“周期”列改为“有效期”，始终显示套餐实际有效时长。
- “不限购”“永久限购”“有效期内限购”只作为购买限制说明展示。

## 影响范围

- 后台套餐管理页面。
- 套餐创建和编辑表单。
- 套餐列表展示。

## 验证方式

- 选择“不限购”时仍能看到并编辑套餐有效期。
- 保存时没有有效期会被前端拦截。
- 套餐列表显示有效期，而不是把“不限购”误显示到有效期列。
- 前端类型检查通过。
