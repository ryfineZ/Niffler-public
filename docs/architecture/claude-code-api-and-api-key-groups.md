# Claude Code 兼容 API 与 API Key 分组修复

## 目标

- 支持接入第三方 Claude Code 兼容 API，例如自定义上游地址和 Bearer Token 认证。
- Claude Code 兼容 API 的 `claude:messages` 请求保持 Claude Code 客户端语义，不转换成其他协议。
- 修复 API Key 分组保存和校验规则，保证请求实际按 API Key 绑定分组执行。
- 删除用户分组时，如果仍有 API Key 使用该分组，返回清楚的占用提示。
- 优化用户分组里的模型销售倍率设置，管理员可以按提供商批量给模型填倍率。
- 修正钱包充值页的预计支付展示，避免把汇率误看成付款金额。

## 非目标

- 不启用官方 Claude Code OAuth 提供商。
- 不改变管理员后台角色权限；管理员账号可以没有用户分组。
- 不改变套餐规则；套餐仍按套餐自己的可用模型和额度判断。

## 行为变化

| 范围 | 修复后行为 |
|---|---|
| 提供商类型 | 新增 `Claude Code 兼容 API`，用于第三方 Claude Code API。 |
| 上游地址 | 新类型允许填写自定义地址，不使用固定官方地址。 |
| 上游认证 | 默认按 Bearer Token 发给上游，不再误用 `x-api-key`。 |
| 请求头 | 透传或补齐 Claude Code 必需请求头，例如 `anthropic-version` 和 `anthropic-beta`。 |
| 请求体 | 只做 Claude Code 必要清理，不做 OpenAI、Gemini 或其他格式转换。 |
| 上游错误 | 上游明确返回 400 时直接返回真实错误，不包装成 503。 |
| API Key 分组 | API Key 必须绑定一个可用分组；请求按这个分组判断模型、接口、限速和钱包倍率。 |
| 删除用户分组 | 如果还有 API Key 属于这个分组，拒绝删除并提示管理员先迁移或删除这些 API Key。 |
| 公开分组 | 所有用户创建 API Key 时可选。 |
| 内部分组 | 只有管理员分配给用户后，该用户的 API Key 才能选择。 |
| 管理员操作 | 管理员替用户创建或编辑 API Key 时，也必须遵守目标用户的可选分组规则。 |
| 分组模型倍率 | 管理员可以在每个提供商旁填写倍率并应用，页面自动写入该提供商关联的全部模型。 |
| 充值预计支付 | 只显示充值金额乘汇率后的付款金额，汇率单独显示为换算说明。 |

## 影响范围

- 提供商创建、编辑、服务账号认证方式。
- Claude Messages 请求的本地上游转发。
- 上游错误返回和重试判断。
- 用户侧和管理侧 API Key 创建、编辑、分组校验。
- 用户分组删除接口和后台删除失败提示。
- 用户分组编辑弹窗里的销售倍率设置。
- 用户钱包充值页的金额展示。

## 验证方式

- 单元测试覆盖 Claude Code 兼容 API 的认证方式和请求头。
- 单元测试覆盖上游 400 直接返回，不重试包装成 503。
- 单元测试覆盖 API Key 分组更新生效，以及内部分组越权绑定被拒绝。
- 单元测试覆盖分组无成员但仍被 API Key 使用时，删除返回清楚的 409 提示。
- 前端类型检查或相关测试通过。
